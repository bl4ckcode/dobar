# BarZ Pilot Onboarding Checklist

**Bar Location / Name:** ____________________  
**Date Onboarded / Go-Live Target:** ________  
**Owner / Manager:** ____________________  
**BarZ Onboarding Lead:** ____________________

---

## 1. Pre-Contract & Discovery

- [ ] Initial meeting / pitch with owner/manager  
  - Present BarZ value proposition (increased throughput, lower friction, marketing tools)  
  - Show mockups, order flow demo  
- [ ] Survey the bar’s current POS, WiFi, staff capabilities  
- [ ] Collect bar legal details: business name, address, tax ID, bank account(s) for settlement  
- [ ] Agree on terms: commission %, free period (if any), Pro plan, hardware (monitor) offer  
- [ ] Send draft Participation Agreement and onboarding terms  

---

## 2. Contract Signing & Setup

- [ ] Owner signs Participation Agreement + exhibits (menu import, hardware loan, etc.)  
- [ ] Collect required documents (business registration, proof of ownership, bank account docs)  
- [ ] Create bar in backend (merchant account, initial settings)  
- [ ] Set up hardware (monitor, tablet if any) to be shipped or installed  
- [ ] Prepare promotional materials: QR stickers, table coasters, signage “We Accept BarZ”  

---

## 3. Menu & Catalog Integration

- [ ] Get menu data (CSV, spreadsheet, digital format)  
- [ ] Confirm categories, items, prices, modifiers, add-ons  
- [ ] Upload menu into BarZ system (or assist owner to upload)  
- [ ] Validate images, descriptions, translation if needed  
- [ ] Confirm order flow (which items are “bar only”, “kitchen”, “drinks”, etc.)

---

## 4. Hardware Installation & WiFi / Networking

- [ ] Place monitor / display in bar space (kitchen, back counter, or visible area)  
- [ ] Connect monitor / tablet to WiFi or wired network  
- [ ] Test WebSocket/order feed to that hardware  
- [ ] Place QR stickers/coasters at tables, bars, entrances  
- [ ] Confirm scanning works and deep-links to menu  

---

## 5. Staff Training & Dry Run

- [ ] Train bar staff / waiters / kitchen on BarZ interface (accept, decline, status change)  
- [ ] Walk through lifecycles: order placed → accepted → preparing → ready → delivered  
- [ ] Conduct a dry-run: simulate orders (with test mode)  
- [ ] Gather feedback and fix UI/UX quirks (button labeling, speed)  

---

## 6. Launch Preparation & Marketing

- [ ] Announce BarZ acceptance: social media, local signage, in-bar signs  
- [ ] Schedule a “launch night” promo (e.g. 30–50% off first BarZ orders)  
- [ ] Set up push notification / in-app message to nearby users (if any)  
- [ ] Provide QR to owner (for them to share on social)  

---

## 7. Monitoring & Support (First 2–4 weeks)

- [ ] Monitor scanning → install → first order funnel metrics daily  
- [ ] Weekly check-ins with owner / manager  
- [ ] Provide hypercare support: immediate bug fixes, UI tweaks  
- [ ] Collect feedback, log feature requests  
- [ ] After first 30 days, evaluate performance and propose conversion to Pro / full contract  

---

## 8. Post-Pilot Wrap-up

- [ ] Aggregate metrics: orders per day, revenue, commission collected, AOV, drop-off rates  
- [ ] Present performance report to owner  
- [ ] Negotiate ongoing contract (beyond pilot)  
- [ ] Transition to full support mode, deactivate pilot-only perks if agreed
