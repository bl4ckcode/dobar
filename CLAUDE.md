# Dobar context adapter

Read and follow [AGENTS.md](AGENTS.md), then the affected area's instructions. Use [the agent workflow](docs/AGENT_WORKFLOW.md) for specs, roles, handoffs, and verification.

Canonical skills live in `.agents/skills`; `.claude/skills/<name>` links to them. Role/model preferences live in `.agents/roles`; profiles do not invoke models or grant permissions.
